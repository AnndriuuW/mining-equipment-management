
# Mining Equipment Management System

Sistema de gestión de equipos mineros y control de mantenimiento.

## Tecnologías

- React + Vite + TypeScript
- Java 21
- Spring Boot 3
- Spring Data JPA
- PostgreSQL
- Flyway
- Git

## Funcionalidades

- Registro de equipos mineros.
- Consulta, edición y eliminación.
- Control de horómetros.
- Alertas de mantenimiento.
- Historial de mantenimientos.
